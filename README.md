## 1️⃣ Data Preparation

The marketing dataset was imported into Microsoft Power BI.

The data preparation process included:

- Reviewing the dataset structure
- Checking and preparing data types
- Organizing categorical fields
- Preparing date-related fields
- Preparing the data for analysis and visualization

---

## 2️⃣ Data Transformation

Power Query was used to prepare the data for analysis.

The transformation process focused on organizing and preparing the available fields so they could be used effectively in the dashboard.

The main steps included:

- Data cleaning
- Data type preparation
- Preparing date fields
- Organizing categorical fields
- Preparing data for reporting

---

## 3️⃣ Data Modeling

The prepared data was structured inside Power BI to support interactive analysis.

The dashboard allows marketing performance to be analyzed across different dimensions, including:

- Month
- Channel Used
- Location
- Campaign Type

---

## 4️⃣ KPI Development

Several KPIs were created to provide a quick overview of marketing performance.

### Revenue

Measures the total revenue generated from marketing campaigns.

### Net Profit

Measures the total net profit generated from the campaigns.

### Average ROI

Measures the average return generated from marketing investments.

### Average Conversion Rate

Measures the average conversion rate generated by marketing activities.

### Cost Per Click (CPC)

Measures the cost associated with generating clicks.
